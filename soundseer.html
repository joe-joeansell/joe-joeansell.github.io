Soundseer - Deaf Inclusive Music Visualiser

2026 University Project. P5.JS music visualiser designed to display the emotions of music visually, for the benefit of deaf or hard of hearing users.

P5.JS | JavaScript | AI-Assisted | Accessibility | Audio Programming

This was a project focused around coding with audio-related techniques. I chose to approach the project from a "pro-social" angle, creating a music visualiser to enhance the music-listening experience for deaf or hard of hearing users. The visuals on screen change colour and shape dynamically to reflect the emotional beats and volume of music.

GitHub repository for this project can be found here.

This project was also an experiment in "AI-Assisted" coding, using tools such as CoPilot and Claude to ideate, bug-fix and suggest code implementations. I came up with the final project idea and much of the visual direction, and used AI to augment and add new elements to my code, whilst scrutinising it's input.

It's primarily p5.js, with the reactive visuals being controlled by a JSON file tuned to the song, instructing the visuals on when to change.
